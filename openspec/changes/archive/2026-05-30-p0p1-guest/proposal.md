# P0+P1：甲方视角隔离 + 验收确认 + 快速评论

## 背景

当前应用无权限区分，甲方登录后能看到所有内部任务。同时缺少验收确认流程和快速评论能力。

## 范围

### P0：甲方视角隔离

- TopNav 新增角色切换：项目管理 / 甲方
- 甲方模式：只显示 `source=jiafang` 的任务
- 甲方模式下隐藏：人员负载面板、内部任务进度
- FilterBar 自动锁定为「甲方任务」
- 甲方模式下的 Dashboard 调整为甲方视角（只看甲方任务统计）

### P1-1：甲方验收确认

- 列新增"待验收"状态
- 状态流：审核中 → 待验收 → 已完成
- 仅甲方角色可将「待验收」改为「已完成」，项目方可从「审核中」推到「待验收」
- TaskCard 在待验收状态显示"待甲方验收"标签

### P1-2：看板快速评论

- TaskCard 底部新增快速评论输入框（默认折叠，点击展开）
- 输入后回车直接发送，不进入 Modal
- 评论数实时更新

## 不做什么

- 不做真正的登录认证
- 不改数据库 schema（待验收只是 status 值增加）
- 不改 Modal 结构

## 角色切换实现

```
TopNav 新增下拉：
  ┌─ 项目管理 ─┐  ← 默认角色，看全部
  └─ 甲方视角 ─┘  ← 只看 source=jiafang
```

通过 React state 传递当前角色到各组件。
