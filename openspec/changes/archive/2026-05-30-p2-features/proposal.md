# P2 功能补齐：人员负载 + 列分布图 + 标签系统

## 背景

P0（逾期/子任务/备注）、P1（删除/汇报表格）已完成。还差三项 Dashboard 增强功能。

## 范围

### 1. 人员负载面板

- Dashboard 新增"人员负载"面板
- 每人一条：头像 + 姓名 + 任务总数 + 负载进度条
- 负载 = 进行中任务数 / 总任务数
- 颜色：绿色 < 40%、黄色 40-70%、红色 ≥ 70%

### 2. 列分布图

- Dashboard 新增"列分布"面板
- 每列一条：色点 + 列名 + 数量 + 水平柱状图
- 柱状图宽度按最大列任务数等比例

### 3. 标签系统

- Task 类型新增 `tags: string[]` 字段
- 数据库 tasks 表新增 `tags` 列
- TaskModal 支持输入逗号分隔的标签
- TaskCard 显示标签（小 badge）
- FilterBar 支持按标签筛选

## 不做什么

- 不碰多项目/用户角色/认证
- 不改现有看板拖拽逻辑

## 技术约束

- Task `tags` 以 JSON 数组存入 SQLite（`TEXT DEFAULT '[]'`）
- 筛选通过前端 `filter` 实现
