# P1 功能补齐：任务删除 + 汇报表格视图

## 背景

P0 已完成（逾期预警、子任务、备注）。还差两个提升实用性的功能：
- **任务删除**：TaskModal 缺少删除按钮，目前无法从 UI 删除任务
- **汇报表格视图**：index.html 原型有独立的"汇报" tab，完整表格适合发给老板/打印

## 范围

### 1. 任务删除

- TaskModal 底部新增"删除"按钮（仅编辑模式显示）
- 点击后 confirm 确认
- 调用 DELETE API 删除任务（级联删除子任务和备注）
- 删除后刷新看板

### 2. 汇报表格视图

- App 新增第三个视图 tab："汇报"
- 独立表格页面，列：序号、任务名称、来源、优先级、状态、负责人、截止日期、子任务进度、备注数
- 逾期行高亮
- 适合打印/截图/导出

## 不做什么

- 不改现有看板逻辑
- 不改 Dashboard
- 不改数据库 schema
